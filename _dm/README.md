# DM side

Notes for the DM. Players should not read this folder.

- It is in the repo so that it stays with the site and is not lost.
- It is **not published**. The deploy drops `_dm/` from the site, and the
  folder name starts with an underscore so a branch-based Pages build skips it too.
- The repo itself is public. Anyone who opens it on GitHub can read these files.
- This is a holding place. Files are dropped here as they are made, so that
  everything is in one spot when the DM section is built.
